7
Competitive Landscape
Positioning: answer depth (documents → reasoned decisions) vs. memory structure (flat index → typed graph)
quadrantChart title Enterprise knowledge tools x-axis Flat document index --> Structured decision memory y-axis Returns documents --> Synthesizes reasoned answers quadrant-1 Memory layer - our target quadrant-2 AI answer bots quadrant-3 Classic search quadrant-4 Manual knowledge bases "Glean": [0.38, 0.62] "Notion AI / Confluence AI": [0.30, 0.55] "Slack AI search": [0.22, 0.45] "Elastic / internal search": [0.12, 0.15] "ADR repos (manual)": [0.62, 0.20] "Wikis (manual)": [0.55, 0.12] "Dashworks / Qatalog": [0.35, 0.50] "Whybase for Teams": [0.85, 0.85]
Key differentiators vs. AI search (Glean et al.): a persistent typed decision graph (revisits/resolves edges), decision status tracking over time, and per-person position attribution — not per-query RAG over a flat index. Vs. manual ADRs/wikis: zero authoring burden — memory forms automatically from the tools people already use.
